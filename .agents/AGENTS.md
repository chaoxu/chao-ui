# Chao UI authority

`chao-ui` defines the visual system maintained in this repository. Apply its tokens, components, and design guidance to work that adopts the system. Preserve an established product theme and follow an explicitly requested alternative.

Use the [README task router](../README.md#choose-a-task) to select the guide, implementation, and specimen for the work. Follow its read order for new artifacts and routine edits.

- Read the affected guide sections and implementation before changing them. Use the [authority and extension boundaries](../README.md#authority-and-extension) to decide where a rule or reusable pattern belongs.
- Check the rendered artifact against the selected guide's validation rules and the [interface standard](../README.md#interface-standard). Include relevant keyboard, focus, responsive, interaction-state, and reduced-motion checks. Font or renderer changes also use the [typography specimen](../specimens/typography-slides.md).
- Preserve the documented local asset paths, licenses, and third-party notices. Review required credits before reusing external material, and distinguish illustrative graphics from measured evidence.
